## v1.0.0

First public stable release.

Highlights:

- reusable WeMM-Embedding-9B runtime for Kaggle T4 ×2;
- FP16 dual-GPU placement;
- text, image, and image+text embeddings;
- 4096d / 1024d vectors;
- bilingual/cross-modal Qdrant retrieval;
- loopback FastAPI;
- public production-style Kaggle notebook;
- reproducible semantic and visual scorecards;
- MIT licensing, CI, community files, and bilingual documentation.
