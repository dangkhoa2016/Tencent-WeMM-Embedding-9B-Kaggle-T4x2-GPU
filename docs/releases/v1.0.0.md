# v1.0.0 — First Public Stable Release

> 🌐 Language / Ngôn ngữ: **English** | [Tiếng Việt](v1.0.0.vi.md)

**v1.0.0** is the first public stable release of the independent **Tencent-WeMM-Embedding-9B-Kaggle-T4x2-GPU** integration project for the upstream **WeMM-Embedding-9B** model, developed by the **WeChat Vision Team at Tencent**. This repository is not an official Tencent or WeChat release.

## Highlights

- reusable multimodal Python runtime;
- verified FP16 dual-T4 placement;
- text, image, and image+text embeddings;
- 4096d and 1024d normalized Matryoshka vectors;
- bilingual English/Vietnamese semantic retrieval;
- image→text cross-modal retrieval;
- controlled visual robustness retrieval;
- verified Qdrant snapshot reuse;
- loopback FastAPI;
- public Kaggle notebook;
- bilingual documentation, MIT license, and CI.

## Release distribution

The GitHub Release intentionally has **no manually uploaded assets**.

GitHub automatically exposes source archives for the tagged tree as:

- **Source code (zip)**
- **Source code (tar.gz)**

These generated archives are convenience downloads for the tagged source. The canonical release documentation remains versioned in this repository under `docs/releases/`.

Model weights and the verified Qdrant snapshot dataset are distributed separately through their documented Kaggle inputs rather than through GitHub Release assets.
