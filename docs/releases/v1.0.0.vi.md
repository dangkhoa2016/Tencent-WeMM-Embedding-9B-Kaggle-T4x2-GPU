# v1.0.0 — Bản phát hành ổn định công khai đầu tiên

> 🌐 Language / Ngôn ngữ: [English](v1.0.0.md) | **Tiếng Việt**

**v1.0.0** là stable release công khai đầu tiên của dự án tích hợp Tencent WeMM-Embedding-9B trên Kaggle T4×2.

## Điểm nổi bật

- reusable multimodal Python runtime;
- verified FP16 dual-T4 placement;
- text, image và image+text embeddings;
- vector Matryoshka chuẩn hóa 4096d và 1024d;
- semantic retrieval Anh/Việt;
- image→text cross-modal retrieval;
- controlled visual robustness retrieval;
- verified Qdrant snapshot reuse;
- loopback FastAPI;
- public Kaggle notebook;
- bilingual documentation, MIT license và CI.

## Phân phối release

GitHub Release chủ ý **không có manually uploaded asset**.

GitHub tự động cung cấp source archive của tagged tree dưới dạng:

- **Source code (zip)**
- **Source code (tar.gz)**

Hai generated archive này là convenience download của source tại tag. Canonical release documentation vẫn được version trong repository dưới `docs/releases/`.

Model weights và verified Qdrant snapshot dataset được phân phối riêng qua các Kaggle input đã document, không đưa vào GitHub Release assets.
